# C-Learning
C code written by a Chinese beginner while learning.

## Current Features
* Input student grades
* Display student grades
* Find the highest and lowest scores
* Count the number of students in each grade range

## Known Limitations
* **No data persistence:** Cannot save or load data (no file I/O).
* **Input buffer issue:** Fails to clear the input buffer properly.
## 👋 About Me
I am an 8th-grade student in 2026 from China. 

## 🛠️ Development Environment
This project is coded and compiled entirely on an Lenovo TB-X804f Android tablet device:
*   **Terminal:** Termux
*   **Compiler:** clang
*   **Editor:** nano
